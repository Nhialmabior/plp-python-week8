PERSONAL MINI-TOOLKIT PLAN

PROJECT TITLE:
To-Do List Manager

PROJECT DESCRIPTION:
This program is a simple To-Do List Manager that allows the user to add,
view, complete, and remove tasks from a personal task list.

TOOLS:

1. Add Task
The Add Task tool allows the user to enter a new task and add it to the to-do list.

2. View Tasks
The View Tasks tool displays all tasks currently stored in the to-do list.

3. Complete Task
The Complete Task tool allows the user to select a task and mark it as completed.

4. Remove Task
The Remove Task tool allows the user to select a task and remove it from the list.

5. Quit
The Quit option allows the user to safely exit the program.
