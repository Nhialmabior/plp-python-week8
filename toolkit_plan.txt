PERSONAL MINI-TOOLKIT PLAN

PROJECT TITLE:
To-Do List Manager

PROJECT DESCRIPTION:
A simple command-line Python application that allows a user to add, view,
complete, and remove tasks from a personal task list.

TOOLS:
1. Add Task - asks the user for a task and adds non-empty input to the list.
2. View Tasks - displays all current tasks with numbered positions.
3. Complete Task - marks a selected task as completed.
4. Remove Task - removes a selected task from the list.
5. Quit - exits the application safely.

CONCEPTS USED:
- Variables, lists, and list indexing
- input() and print()
- append() and pop()
- Functions and function arguments
- if / elif / else conditional statements
- for and while loops
- enumerate() and f-strings
- Basic input validation and string methods
- Basic automated testing with unittest

VALIDATION:
The application rejects empty tasks, non-numeric task numbers, and task
numbers outside the available list. Invalid menu choices display a helpful
message rather than terminating the program.

CURRENT LIMITATION:
Tasks are held in memory and are cleared when the program exits.
Persistent storage is listed as a possible future improvement.
